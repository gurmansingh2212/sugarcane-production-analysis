# Sugarcane Production Analysis

A Python-based data analysis project that explores sugarcane production across different countries and continents. This project uses Pandas, Matplotlib, and Seaborn to perform data cleaning, exploratory data analysis, statistical analysis, and data visualization.

## Project Objectives

- Analyse sugarcane production across different countries.
- Compare sugarcane production across continents.
- Identify countries with the highest production.
- Analyse cultivated acreage and yield.
- Explore relationships between production and agricultural area.
- Visualize patterns using graphs and charts.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Dataset

The project uses the following dataset:

`List of Countries by Sugarcane Production.csv`

The dataset contains information about:
- Country
- Continent
- Production (Tons)
- Production per Person (Kg)
- Acreage (Hectare)
- Yield (Kg / Hectare)

## Installation and Usage

1. Clone this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

```bash
pip install pandas matplotlib seaborn jupyter
```

4. Keep the CSV dataset in the same folder as the notebook.
5. Open Jupyter Notebook.
6. Run `Sugarcane_production.ipynb` cell by cell.
